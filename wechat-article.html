我把学而思、作业帮、高途的数学方法，做进了一个能自己出题的网页里

纯前端 · 离线可用 · MIT 开源 ｜ 小学到高中 49 个核心解题方法，每练一遍题都不重样

一、刷题刷不出效果，问题到底出在哪

辅导孩子数学这些年，我发现一个特别普遍的现象：同一类题，今天做对明天错；卷子刷了一堆，换个问法又懵了。

后来我研究学而思、作业帮、高途这些机构的体系，不得不服——它们把小学数学方法梳理得很清楚：鸡兔同笼、植树、盈亏、工程、相遇追及……初中高中也是，函数、几何、数列、导数、圆锥曲线，方法都是成体系的。

但光看方法不够，关键是"针对一个方法反复练，而且每次题都不一样"。市面上的练习册，一题印死了，孩子背下答案就糊弄过去了，没真懂。

所以我干脆自己动手，把这帮机构的核心方法整理成一个网页应用：每个方法有讲解、有配图、有动图，最重要的是——它能自己出题，每遍都不一样。

二、它到底是个什么东西

一句话：一个用浏览器打开就能用的数学方法练习册。纯前端网页，不联网也能跑，不需要装任何 App，手机电脑都能开。

所有方法按年级和依赖关系排成一条"学习路径"，从小学低年级一路到高三。点进去一个方法，先看讲解和图示，再做题巩固，错了自动记进薄弱点，练熟了再往下走。

三、四个我比较得意的点

1. 方法全，小学到高中一条龙

一共接了 49 个核心方法：

阶段方法数代表方法
小学10鸡兔同笼、植树、盈亏、工程、相遇追及
初中15整式、方程、全等相似、勾股定理、函数
高中24数列、向量、立体几何、导数、圆锥曲线、概率统计

小学初中高中全做完了，基本覆盖了课内提分最常用的那批方法。

2. 每练一遍，题都不一样

这是整个东西的核心。每个方法背后都有一个"出题引擎"：第一遍练完，第二遍重新生成一套新题，第三遍再换，永不重样。

而且答案不是我手填的，是引擎用数学公式当场算出来的，正确性有保证。每道题还给分步解析，孩子做错了能看过程，不是只给个对错。

3. 配图配动图，枯燥方法变直观

比如鸡兔同笼，有"抬脚法"的动画演示，一看就懂；相遇追及问题，画两个小人相向而行，路程时间关系一目了然。

几何类方法配的是 SVG 矢量图，只画"题给的数据和结构关系"，绝不把答案直接画上去——逼孩子自己想，而不是照着图抄。

高中部分也一样，圆锥曲线、立体几何这些抽象内容，能画图的尽量画图。

4. 学习路径 + 薄弱点追踪

方法按依赖关系串成一条路径，循序渐进。每个方法有"闯关"模式，错题自动进薄弱点库，专门反复练，直到清空。

练完点"返回路径"，页面会自动滚到刚才练的那个节点并高亮——孩子知道自己学到哪了，不容易迷失。

四、怎么用，怎么拿到

最省事：双击打开 index.html 就能用，不需要联网。

想当网站用：用一行命令起个本地服务就行：

python -m http.server 8142

然后浏览器开 http://127.0.0.1:8142/。也可以部署到 NAS 或服务器，全家设备局域网共享。

开源免费：整个项目 MIT 协议，代码在 GitHub 上，随便用、随便改：

https://github.com/kenowong/math-mastery

五、适合谁

  • 家长：自己不会讲没关系，让孩子跟着方法一步步练，错题自动攒着。
  • 学生：自习、预习、补薄弱点都行，每遍题不重样，不容易腻。
  • 老师：出题参考、课堂演示，参数化生成器能当场变出不同难度的题。
  • 机构：课件素材，MIT 协议随便整合进自己的东西里。

写在最后

这个东西我断断续续做了好一阵，从小学弄到高中，49 个方法、参数化出题、配图配动图，目前能完整跑起来了。它不打算做成收费产品，就一个干净、离线、开源的练习工具，谁用都行。

如果你也在辅导孩子数学，或者自己想系统过一遍这些解题方法，可以去 GitHub 上拉下来试试。有建议、有想加的方法，也欢迎提。
